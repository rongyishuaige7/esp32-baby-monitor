# 验证说明

## CI / 本地门禁可验证范围

每个默认分支提交应运行：

1. 公开文件、凭据、构建输出和危险宣传语扫描；
2. 公开目录、固定依赖、凭据示例、协议与硬件边界的源码契约检查；
3. ESP32 PlatformIO 干净构建；
4. 全 Git 历史 gitleaks 扫描。

这些步骤不连接 ESP32、不烧录固件、不读取传感器、不连接 Wi-Fi，也不运行 Android App。CI Artifact 若存在，仅保留 14 天，不是固件发布、真机记录或长期下载渠道。

## 当前 commit 真机复测仍需完成

在宣称“当前真机已复测”前，至少记录：测试日期、完整 Git commit、ESP32 精确板型/Flash、供电方式、每个传感器/模块版本、接线、电平转换/分压、公共地、串口端口和每项通过/失败/未测结果。

建议逐项验证并保留脱敏证据：

- 固件烧录、启动与重启；
- 两路 HC-SR04 单独/同时读取、无目标/超时和相互干扰路径；
- HC-SR04 ECHO 分压/电平转换后在 ESP32 GPIO 的电压安全性；
- DHT11 正常读取、断线/失败时 `unknown` 路径；
- 声音模块 ADC 输入范围、阈值变化、冷却期和误触发观察；
- RGB LED 的实际极性、颜色、限流和电流；
- 蜂鸣器驱动、电流、静音切换和供电稳定性；
- 两个按钮的外部上下拉、去抖和触发极性；
- 有凭据时连接受控 Wi-Fi、无凭据与连接超时时 HTTP 关闭；
- `GET /api/status` 与 `POST /api/mute`，同时确认 HTTP 回应不被记录为安全、健康或看护结论；
- 30–60 分钟受控运行、重启与断网观察。

真机复测只能证明记录中可见的硬件行为，不能使本项目成为婴儿监护、医疗、睡眠安全、生命安全或紧急告警设备。

## 证据脱敏

照片、视频、屏幕录制和日志必须清除 SSID、密码、私网 IP、MAC、儿童影像、音频、姓名、家庭地址、健康信息、EXIF/GPS 与其他个人数据。旧照片只能作为历史演示证据，不能自动证明当前公开 commit 已通过真机复测。
