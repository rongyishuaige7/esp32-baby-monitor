# Hardware Lab 索引卡片

- **名称：** 基于ESP32的婴儿状态监测原型
- **平台：** ESP32 · Arduino · PlatformIO · HC-SR04 · DHT11 · 模拟声音输入 · WebServer
- **摘要：** 通过两路距离、温湿度和声音幅度输入驱动 ESP32 中的演示级固定阈值分类、RGB/蜂鸣器本地反馈和可选可信局域网 JSON 接口。
- **构建证据：** 发布后填写当前 `main` HEAD 与同一 HEAD 的成功 Actions 运行链接。
- **真机状态：** 源码来源、公开净化、硬件无关源码契约与 ESP32 PlatformIO 构建已验证；当前 ESP32、双 HC-SR04、DHT11、声音模块、RGB LED、蜂鸣器、按钮、Wi-Fi 与 HTTP 尚未按当前公开提交重新真机复测。
- **公开范围：** 当前未公开 Android App、实物照片、演示视频、EDA、PCB、Gerber、制造文件、固件二进制或真实网络/儿童相关材料；已公开固件、BOM、接线边界、协议、来源、状态与验证说明。
- **边界：** 距离组合不是姿态识别，声音幅度不是哭声识别；LED、蜂鸣器、HTTP 和构建不代表安全、医疗、告警送达或有人看护。无 TLS/认证 HTTP 只能用于隔离可信教学局域网。

- **历史媒体 / EDA：** 已加入经脱敏的历史衍生材料；范围和版本差异见 [`MEDIA_EVIDENCE.md`](MEDIA_EVIDENCE.md)。它们不证明当前公开提交已完成真机复测。
